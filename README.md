# DIAN115 用户 WIKI

私人影院主题的独立静态站点。深夜蓝、冷银、电影封面与放映光影，配合八个介绍章节、33 篇指南、21 项内置工具和 16 个门户入口。

## 本地运行

直接打开 `index.html`，或在本目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

随后访问 `http://127.0.0.1:8765/`。无安装依赖、无构建步骤，整个目录可用于静态托管。三个在线 Demo 分别进入管理端、用户门户与音乐播放器。

## 文件结构

- `index.html`：八章主页、媒体视觉与 Demo 入口。
- `content.js`：功能、配置、个人使用、版本、授权和门户指南。
- `style.css`：影院主题、冰蓝浅色主题、响应式与动效。
- `app.js`：搜索、指南阅读器、深链接、配置复制、功能和门户分类。
- `cinema.js`：封面轮转、键盘控制、指针光影、滚动运镜与动画调度。
- `assets/`：品牌标记与本地电影海报；来源见 `ASSETS.md`。

## 动效与交互

首屏采用交错入场、标题光泽、投影光束与漂浮微粒。五张封面通过立体轨道轮转，支持点击、上一张 / 下一张及方向键选择；指针改变封面角度和反光。悬停或聚焦时暂停自动轮转。

页面包含无缝流动片单、章节标题揭幕、滚动视差、工作流信号、功能列表交错切换、配置步骤转场、媒体画面的缓慢运镜、播放进度、音乐节拍、门户筛选与详情转场，以及三种 Demo 动态视觉。

默认开启深色主题与完整动效。顶部的星光按钮开启安静模式，太阳按钮切换浅色主题。系统设置“减少动态效果”时自动关闭动画。页面离开视口或浏览器切入后台时暂停相关动画与自动轮转。

Ctrl / Cmd K 搜索指南，Esc 关闭阅读器。指南支持 `#guide/organize` 等直接链接。字体可从 Google Fonts 加载，网络不可用时使用系统字体；核心交互和本地媒体图像无需外部请求。

## 文档版本

适用 DIAN115 v4.0.96。高级版最多 10 个门户小号、3 个 Emby 代理实例；S.O. 无该门户人数上限，最多 6 个代理实例，并支持独立群组管理机器人。授权类型、获取方式与有效期通过官方 @succt 确认。

配置指南包含 CloudDrive2 的 Linux Docker 部署、FUSE 与共享挂载、API Token 与自动读取，以及 CD2 / DIAN115 / Emby 的路径对照和 FlareSolverr 接入。授权章节与指南均显示官方捐赠二维码，支持打开原图。
