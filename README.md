# DIAN115 用户 WIKI

以 Cyrclo 为视觉参考重新实现的黑白媒体站点：双层图片圆环、点阵留白、巨型流动字、弧形浅色章节、随滚动放大的媒体卡片与居中下拉菜单。保留八章介绍、42 篇快捷指南、117 篇完整文档、23 项内置工具和 16 个门户入口。

## 本地运行

直接打开 `index.html`，或在本目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

随后访问 `http://127.0.0.1:8765/`。无安装依赖、无构建步骤，整个目录可用于静态托管。三个新版在线 Demo 分别进入管理端、用户门户与 RAVE 媒体空间，默认深色并填充真实作品资料与演示状态。

## 文件结构

- `index.html`：八章主页、媒体视觉与 Demo 入口。
- `content.js`：功能、配置、个人使用、版本、授权和门户指南。
- `style.css`：黑白主题、弧形章节、响应式与动效。
- `app.js`：搜索、指南阅读器、深链接、配置复制、功能和门户分类。
- `cinema.js`：圆环滚动、媒体展示缩放、问答展开、指南轮播与动画调度。
- `assets/`：品牌标记与本地电影海报；来源见 `ASSETS.md`。

## 动效与交互

首屏由 12 张内圈与 16 张外圈本地封面组成，方向相反、速度不同。向下滚动时圆环放大并旋转，中心文案淡出，随后进入巨型流动标题、项目介绍和带弧形边界的浅色章节。三张媒体展示卡片随进入视口的进度放大；手机保持完整可读的固定构图。

顶部中央菜单从白色标签下方展开深色浮层；支持连续开合、Esc、焦点回归与键盘范围限制。主按钮文字上下滚动替换，卡片和箭头提供悬停、聚焦与按压反馈。四个功能分类、四步配置及门户筛选即时更新，配合短暂淡入。入门指南轮播支持按钮、方向键、触控板与原生触摸滑动。

六项常见问题使用可中途反向的展开动画。搜索和阅读器成对开合，保留 Ctrl / Cmd K、Esc、教程深链接、配置复制、阅读进度和目录高亮。完整文档继承黑白主题，提供全文搜索、手机目录和主题切换。

顶部星光按钮控制安静模式；深浅主题可手动切换。系统的“减少动态效果”同时约束 CSS 与 JavaScript 动画。循环动画离屏或后台暂停，文档正文直接显示；原生滚动始终保持可用。字体使用系统字族，图片全部来自已有本地素材，核心页面不依赖外部脚本或字体。

视觉分析与交互对照见 [DESIGN-NOTES.md](DESIGN-NOTES.md)，验证范围见 [VERIFICATION.md](VERIFICATION.md)。

## 文档版本

适用 DIAN115 v5.0.42。个人版（高级版）最多 10 个门户小号、3 个 Emby 代理实例；S.O. 无该门户人数上限，最多 6 个代理实例，并支持独立群组管理机器人与推送助手。推送助手仅 S.O. 可用，最多 500 个绑定账号，与门户用户名额分开计算。授权价格为个人版 199 元、S.O. 版 499 元。通过 Telegram 联系 @succt 购买。授权有效期与附加功能以收到的密钥为准。

配置指南优先推荐 Linux / NAS 的 Host 网络部署，提供可直接复制的完整 Compose、启动命令和桥接网络备选。包含 CloudDrive2 的 FUSE 与共享挂载、API Token 与自动读取、CD2 / DIAN115 / Emby 路径对照，以及适用于 Host 和桥接网络的 FlareSolverr 地址配置。授权章节与指南统一提供 Telegram 联系购买入口。
