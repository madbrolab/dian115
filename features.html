FEATURES

功能总览

从发现内容到稳定播放，DIAN115 把每个环节拆成可独立启用的模块。先了解模块职责，再在界面截图中查看实际入口。

探索发现

探索页面聚合 TMDB 热门、分类筛选、PT 搜索和自定义资源源。打开条目后可以直接查看元数据、搜索资源或创建订阅。

TMDB 与趋势

按类型、年份和评分浏览电影、剧集，快速定位想看的内容。

资源搜索

跨 PT 站点或已配置来源搜索，结果可以进入下载或订阅流程。

媒体订阅

订阅记录内容的目标状态、缺集和资源质量。任务会周期性检查新资源，并把符合规则的结果交给转存和整理流程。

  • 电影订阅：关注单个作品的最佳版本。
  • 剧集订阅：追踪季和集，保留缺集状态。
  • RSS / 自定义订阅：按关键词和质量筛选资源。

媒体整理

整理模块负责识别文件、匹配元数据、生成目标目录和记录变更历史。建议先用测试目录确认命名模板，再扩大范围。

!

批量整理前先检查“预览结果”。文件移动、重命名和刮削属于有副作用的操作，确认规则后再执行。

STRM / 虚拟影库

虚拟影库通过生成轻量 STRM 文件，让 Emby 读取云端媒体而不复制实际视频。播放请求再由代理层换成可用的直链。

推荐链路
CloudNAS 挂载 → DIAN115 生成 STRM → Emby 扫描 /media → 播放代理请求云端直链

我的媒体

我的媒体页面聚合已整理内容、播放代理和媒体库状态。遇到“文件存在但 Emby 看不到”，先对比两端的容器内路径。

查看我的媒体截图 →

PT 站点

配置站点地址、认证信息和搜索参数后，可以在探索和订阅流程中复用。每个站点的失败原因会回写到任务日志。

建议

为站点设置独立标签和限速，先用单个关键词验证搜索，再开启自动订阅。

插件中心

插件将通知、Emby 封面、PT 刷流和外部服务整合到统一入口。启用插件后，在对应设置页完成凭据和事件选择。

通知插件

Telegram、Webhook 和自定义模板，详见 通知模板。

媒体插件

封面处理、元数据补全和播放服务联动。
