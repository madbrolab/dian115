FEATURES · PART 2

资源与插件

完整恢复文件管理、主账号与备用 CK、PT 站点、插件中心的 12 个插件以及卫星发布树说明。

07

文件管理

管理容器可见的本地与挂载目录，并直接触发识别、整理和秘享。

入口：文件管理

文件管理器只操作容器已经挂载并允许访问的路径，提供面包屑、网格/列表浏览和批量选择，适合处理待整理目录与少量人工修正。

日常文件操作上传、下载、预览、新建文件夹、重命名、移动、复制、复制路径与删除。
媒体操作对文件或目录执行识别；系统按当前路径选择同模式的已启用整理规则。
分享操作启用秘享空间后，从当前选中项生成内容快照和秘享短码。
!

删除不可撤销。文件管理中的删除直接作用于容器所见路径，不等同于 115 回收站。批量操作前核对当前路径与项目数量。

08

账号池配置

把主账号、备用 CK、目录策略与账号运维分开管理。

入口：账号配置

主账号池

主账号可扫码添加、检查、刷新、编辑和激活；活跃账号供全局 115 客户端使用。可设置自动切换与 API QPS 上限，并查看 Cookie、VIP、空间与签到状态。

备用 CK 池

独立备用池不会成为活跃账号，不参与主账号自动切换、签到、目录设置、批量检查或全局客户端；只有明确支持备用池的功能才会轮询。

  • 为主账号选择真实对应的 CD2 云盘，避免跨账号目录与文件身份错配。
  • 分别设置转存、离线下载、秘享接收目录；可添加备用目录供风控或容量场景切换。
  • 按 TG、癫影、PT 等渠道设置默认目录；PT 秒传只使用转存目录，不回退离线目录。
  • “我的分享”可取消或清理过期记录；“回收站”支持安全码与定期清理。
09

PT 站点相关

站点连接、搜索、RSS、下载与刷流是四层能力，需逐层验证。

入口：站点配置
站点配置维护站点类型、域名与认证信息，单独控制启用、代理、超时、搜索和 RSS。
账户视图刷新上传、下载、分享率、等级、魔力与做种数据，判断账号健康。
任务执行搜索结果进入订阅策略或手动下载，真正落地由 qBittorrent / Transmission 完成。
i

推荐顺序：先验证认证与搜索，再验证下载器连接与保存路径，之后开启 RSS，最后启用 PT 刷流。刷流插件会自动添加和删种，不应当作连接测试工具。

PT 刷流和站点统计的区别

PT 站点统计是只读汇总；PT 刷流会依据促销、H&R、体积、做种数、速度、磁盘与删种规则主动创建和清理任务，风险级别不同。

10

插件中心

原页面中的 12 个插件，逐项保留用途、首次配置和使用边界。

入口：插件中心

文件秒传

本地文件或目录上传 115，优先 SHA1 秒传，失败可回退普通上传。

  • 配置本地源、115 目标、后处理、限速与并发。
  • 失败目录不要放在监控目录内部，避免循环。

多号云迁移

比较主账号与备用账号目录树，按 SHA1 单向补齐目标账号缺失文件。

  • 配置源目录、备用 CK、目标目录和同步方式。
  • 先预览差异；不会反向覆盖主账号。

秘享空间

将文件或媒体生成限时、限次短码，供其他用户领取。

  • 配置接收目录、有效期、领取次数与快照。
  • 账号风控或目录异常会导致领取失败。

Telegram 频道监控

监控频道中的 115 分享、磁链与 ED2K，支持采集、转存、离线和转发。

  • 配置 TG 客户端、频道、转发目标与独立 Bot。
  • 转发 Bot 不要和通知 Bot Token 混用。

Emby 封面生成

为媒体库生成统一风格封面，并刷新或上传回 Emby。

  • 配置媒体库、样式、字体、角标和素材。
  • 支持 AI 翻译、批量/定时生成与缓存清理。

通知插件

把播放、入库、文件、任务、账号与系统告警发送到 Telegram。

  • 配置 Bot Token、白名单、事件和静默时段。
  • 详见独立的通知模板变量手册。

PT 刷流

按站点最新种子自动添加任务，依据速度、空间与规则维护删种。

  • 配置站点、下载器、促销、H&R 和删种规则。
  • 活动任务达到上限时暂停新增。

癫影

通过 OpenAPI Key 完成签到、检索、上传分享、积分与 FFP 管理。

  • 配置账号 Key、签到时段、默认分享账号。
  • 上传可使用分享码或 ED2K。

PT 站点统计

集中查看各站上传、下载、分享率、魔力、做种量和账号健康。

  • 依赖已添加和认证的 PT 站点。
  • 只读统计，不会创建下载或删种。

Emby 媒体画像

从旧 Emby 拉取路径、容器、媒体流和章节，匹配 115 SHA1 形成 FFP。

  • 配置旧 Emby、路径替换与新目录树。
  • 旧库迁移先建树，完成画像后再生成 STRM。

CLASH 监控

监测代理域名健康，联动 Clash / Mihomo Selector 测速与切换节点。

  • 配置控制器、策略组、测试地址与阈值。
  • 先测试控制器和候选节点延迟。

AI 字幕翻译

把已有的非中文字幕源翻译为中文外挂 SRT，显示进度、对照和日志。

  • 配置字幕风格、AI、字符上限与媒体库白名单。
  • 只处理文本字幕，不自动 OCR PGS/DVD 图像字幕。
!

插件并非全部“装好即用”。进入后先完成账号、目录、Emby、Telegram、下载器或代理控制器等依赖检查。

11

卫星发布树

把指定 STRM 规则的文件树安全发布给其他 DIAN115 子服务实例。

入口：卫星任务

主实例选择 STRM 规则发布文件树，再为每个子服务创建独立客户端。客户端使用 API Key 读取授权规则树，并通过心跳报告版本、状态与本地文件数量。

发布范围按 STRM 规则发布，不会暴露全部目录和账号数据。
客户端控制设置名称、允许规则、过期时间和备注；API Key 创建后立即保存。
审计查看在线状态、最后心跳、请求次数、同步/分享类型、状态和来源 IP。
!

API Key 按客户端隔离，不要让多个子服务共用。某个客户端失陷或退役时，只吊销对应凭据。
