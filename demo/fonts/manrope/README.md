# Manrope

Manrope 可变字体，200–800 字重。仅在 RAVE 前台字体栈中使用，中文沿用系统字体。

来源：Google Fonts 官方仓库 `ofl/manrope/Manrope[wght].ttf`，2026-10-19 下载并以 `Manrope-variable.ttf` 原样保存。
