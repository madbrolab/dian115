把部署时不常改、运行中经常查的内容集中在这里：端口、路径、环境变量、任务状态和维护命令。

端口与入口

端口用途备注
8095DIAN115 Web 控制台默认浏览器入口。
8098播放代理 / 服务接口按实际启用的媒体服务使用。
4534附加服务入口桥接网络下需要显式映射。

路径速查

路径内容排查重点
/config应用数据、账号和日志容器是否可写，是否纳入备份。
/media本地媒体和整理结果与 Emby / Navidrome 的路径是否一致。
/CloudNAS云端挂载目录挂载传播、读取权限和目录是否为空。

环境变量

最小 Compose 只需要时区；其余设置优先在 Web 配置中心完成，避免把敏感值写入公开文件。

environment
TZ: Asia/Shanghai
!

不要把账号 Cookie、Bot Token、Webhook 密钥或数据库内容提交到公共仓库。

任务队列状态

等待中

任务已经创建，等待并发槽位或前置任务完成。

运行中

正在执行转存、识别、整理、刮削或 STRM 生成。

已完成

任务产生了预期结果，可在日志中查看摘要。

失败

先展开错误详情，再结合账号、路径和网络状态排查。

缓存与更新

缓存中心用于清理元数据和任务相关缓存；容器更新页面用于查看版本摘要和执行更新。清理缓存前确认没有正在运行的大批量任务。
