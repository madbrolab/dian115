01 · START

五步完成一个模板

  1. 选择事件在推送模板设计器中先选具体事件。
  2. 插入变量只使用当前事件右侧列出的变量。
  3. 隐藏空值可选字段用 if 包住整行。
  4. 检查预览确认富文本、链接与图片均正常。
  5. 保存配置导入或编辑后必须保存才生效。
没有通用业务模板不同事件之间不会继承变量。复制模板前必须核对目标事件的变量表。
02 · SYNTAX

模板语法

{{ title }}输出变量

不存在或为空时输出空字符串。

{{ title or '未知' }}默认文字

左侧为空、0 或 false 时使用后备值。

{% if rating %}...{% endif %}可选内容

字段为空时整段隐藏。

{% if a and not b %}条件组合

支持 and、or、not、==、!=。

{% elif value %}多分支

支持 elif、else 与嵌套条件。

不支持 loop / filter安全边界

不执行函数、过滤器、循环或任意代码。

04 · LINKS & IMAGE

媒体链接、画质点评与头图

TMDB / IMDb 文字超链

{{ tmdb_link }} 与 {{ imdb_link }} 显示可点击文字，不输出裸链接。自定义文字用对应的 _start / _end 包住。剧集始终指向整部剧。

可编辑画质点评

quality_comment 按 Dolby Vision、HDR/HLG、4K/UHD、1080P/Full HD 顺序识别，一条通知只显示最高档。8 个质量事件分别保存四档文案，清空某档即可关闭。

自动图片

有明确 TMDB 图片时优先使用；否则使用当前事件后端默认图。默认图真实地址不进入前端或导出包。

自定义 / 关闭

自定义链接必须在 3 秒内预览成功。关闭模式在没有 TMDB 图片时回退纯文本。

05 · PORTABILITY

导入与导出

  • 全量导出包含全部 39 个事件；选择导出只包含勾选项。
  • 导出不包含 Bot Token、白名单、通知开关或后端默认图地址。
  • 导入逐项校验事件、变量、语法和富文本配对，并支持逐项预览与选择。
  • 自定义图片导入后必须重新通过 3 秒校验。
  • 应用导入只更新页面编辑状态，最后仍需保存通知配置。

常见问题

变量为什么在另一个模板里不能用？

每个事件独立校验。设计器当前事件显示的变量列表是唯一可信清单。

为什么只显示图标或标签，没有值？

固定文字没有放进条件块。把整行写成 {% if rating %}⭐ {{ rating }}{% endif %}。

为什么 TMDB / IMDb 或画质点评没有出现？

这些都是条件变量。没有对应媒体 ID，或质量不是 DV/HDR/4K 时会保持为空。

为什么导入后没有生效？

应用导入只是写入当前编辑状态，仍需点击页面底部“保存通知配置”。

为什么长内容被截断？

Telegram 有单条消息长度限制。Dian115 会安全截断而不拆成多条；长内容建议放入可展开引用。
