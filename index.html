01 · INSTALL

部署只需三步

先固定持久化和路径，再启动容器，后续的 Emby、STRM 与整理规则才不会反复返工。

1

准备目录

为配置、媒体与 CloudNAS 准备宿主机目录，建议分别映射到 /config、/media、/CloudNAS。

2

启动 Compose

Linux、NAS 与 Unraid 推荐使用 host 网络；桥接网络则显式映射 8095、8098 和 4534。

3

完成验收

打开 http://服务器IP:8095，设置管理员密码，检查目录可见性并确认容器重启后配置仍在。

02 · CONFIG

一份可直接修改的 Compose

示例只保留最小必要字段；生产环境请替换宿主机目录，并按需增加代理或时区配置。

docker-compose.yml
services:
  dian115:
    image: madbrolab/dian115:latest
    container_name: dian115
    restart: unless-stopped
    network_mode: host
    volumes:
      - ./config:/config
      - ./media:/media
      - ./CloudNAS:/CloudNAS:shared
    environment:
      - TZ=Asia/Shanghai
i

路径提示　CloudDrive2、dian115 与 Emby 看到同一媒体时，容器内路径要保持一致；不要在桥接网络里把 127.0.0.1 当作宿主机地址。
