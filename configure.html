COMPLETE CONFIGURATION

完整配置流程

按“基础连接 → 资源来源 → 自动化 → 对外服务”的依赖顺序完成接入，并恢复原 Wiki 的旧 Emby 库迁移、关键配置卡片和上线检查。

推荐配置顺序

  1. 管理员与授权设置管理员密码并完成 License 激活；确认容器重启后密码、激活状态和数据库都能保留。
  2. 115 主账号与目录扫码添加账号，选定活跃主账号，保存安全码，并设置转存、离线、秘享接收及各渠道默认目录。
  3. CloudDrive2填写 CD2 地址、API Token 与容器内挂载根，例如 /CloudNAS；选择主账号实际对应的云盘并执行连接测试。
  4. 判断是否迁移旧 Emby 库已有其他工具生成的媒体库时，先完成“Emby 媒体画像 → Madby → FFP”迁移链路，不要立即大规模生成新 STRM。
  5. 媒体服务与外部接口接入 Emby / Navidrome，按需生成 OpenAPI Key，配置 Webhook、Madby、HTTP 代理和 TMDB 网络。
  6. 下载器与资源来源先让下载器连接成功、保存路径正确，再添加 PT 站点、RSS、Telegram 频道监控和癫影账号。
  7. 订阅、整理与 STRM先用一个小目录测试识别、命名、洗版和多版槽位；STRM 先全量建树，再生成文件，最后开启实时或定时同步。
  8. AI、通知与门户最后配置 AI 提供商、Telegram 通知、门户和卫星服务，它们依赖前面的账号、路径与媒体服务。

旧 Emby 库迁移：先保留画像

如果旧 Emby 媒体库由其他工具生成，“Emby 媒体画像”不是普通辅助插件，而是迁移链路的第一步。目标是把旧路径、媒体流信息与 SHA1 画像先匹配和上报，避免新旧条目混在一起。

  1. 完成最小连接配置管理员、授权、115 主账号、CD2 地址/API Token 与挂载路径。
  2. 只构建目录树在 STRM 规则中先同步目录树，暂时不要生成 STRM，也不要让新 Emby 大规模扫描。
  3. 拉取旧库画像进入“插件中心 → Emby 媒体画像”，填写旧 Emby 地址与 API Key，读取旧库条目、文件路径和媒体流信息。
  4. 配置路径替换把旧 Emby 文件路径映射到 DIAN115 新的 115 / CD2 目录树，检查匹配率和未匹配记录。
  5. 接入 Madby填写 DIAN115 地址与 OpenAPI Key；避免原生 Webhook 和 Madby 对同一事件重复通知。
  6. 上报 FFP将可用画像上报到癫影 SHA1 FFP，尽量保留旧库的容器、媒体流、章节与技术字段识别成果。
  7. 最后切换新库确认路径、Madby、FFP 和通知正常后，再生成新 STRM，并让新的或干净的 Emby 媒体库扫描。
!

不要同时迁移与大规模扫描。旧路径尚未匹配时就生成新 STRM，会把旧库画像、新 STRM 和新 Emby 条目混在一起。

关键配置

系统设置

  • 基础：CD2 地址、挂载路径、系统参数、HTTP 代理。
  • 安全与 API：登录密码、两步验证、OpenAPI Key。
  • 词表：识别替换词、制作组、占位符与分类词表。
  • 高级：Webhook、AI 提供商池、背景及外部集成。

账号配置

  • 主账号参与全局 115 客户端、签到、目录和自动切换。
  • 备用 CK 池独立存在，不会自动成为活跃主账号。
  • QPS 限制按账号负载设置，高并发不等于更稳定。
  • 转存、离线与秘享目录用途不同，不建议指向同一临时目录。

媒体路径

  • Emby、DIAN115 和 CD2 对同一媒体的路径必须可转换。
  • 本地整理仅支持本地到本地；硬链接要求同一文件系统。
  • CD2 整理要求源与目标都在 CD2 挂载根下，操作由 CD2 完成。
  • 混合“本地 → CD2 / CD2 → 本地”不属于整理规则范围。

AI 与外部接口

  • AI 支持 OpenAI Chat Completions 或 Responses 协议。
  • 每个使用位置可以单独选择提供商和模型。
  • Webhook / Madby 使用 OpenAPI Key，密钥不要出现在截图和日志。
  • 管理模式 AI 可调用后台工具，应保留危险操作确认。

容器路径规范

容器路径用途重点
/config账号、数据库、日志和应用设置必须可读写并纳入备份。
/dian115AIAI 长期记忆、仓库和工作文件使用 AI / GitHub 工具时持久化。
/media本地媒体、整理输出和 STRM和 Emby 保持一致。
/CloudNASCloudDrive2 云端目录映射保留共享传播，确认主账号云盘。

115 主账号与备用 CK

主账号扫码添加、检查、刷新、编辑和激活；活跃账号供全局客户端使用，可设置自动切换与 API QPS。
备用 CK 池不会成为活跃账号，不参与主账号自动切换、签到、目录设置或全局客户端。
目录隔离分别设置转存、离线和秘享接收目录；PT 秒传只使用转存目录。
i

为主账号选择真实对应的 CD2 云盘，避免跨账号目录与文件身份错配。Cookie、Token 和安全码属于敏感信息，不要提交到公开材料。

检查项通过标准失败时优先检查

PT站点可搜索，下载器能添加测试任务站点认证、代理、保存路径、客户端标签
整理识别测试命中 TMDB，小样本按预期命名词表、来源路径、媒体类型、AI 触发条件
