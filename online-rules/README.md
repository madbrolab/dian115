# dian115 在线整理资源

本目录只维护可由 dian115 用户主动拉取的在线文件，不是应用内置更新器。应用不会定时访问这些地址，不会比较远程版本，也不会提示“有新版本”；只有用户在页面中明确点击拉取并确认后，本地配置才会被替换。

- [`category/`](./category/)：整理分类模板。决定静态分类目录、匹配条件和是否使用合集词表。
- [`collections/`](./collections/)：合集词表。只负责把 `(movie|tv, TMDB ID)` 映射为一个目录分组名称，并明确区分社区分组与 TMDB 官方 Collection。
- [`tools/`](./tools/)：可重复执行的生成和清洗工具。

整理模板与合集词表必须分别提交和审核。不要把数千个合集展开成数千条 Emby 媒体库规则；合集名称是媒体库内部动态子目录，媒体库边界始终来自整理模板中的静态路径。
