# 在线整理分类模板

这里维护可由 dian115 前端主动拉取的 YAML 分类模板。模板只定义静态分类目录、匹配条件和明确声明的动态子层级，不负责合集目录。合集区分由普通/多版命名模板中的独立开关控制，并固定在命名路径最前面。

## 模板选择

| 模板 | 目录特点 | 适合需求 | 特别影响 |
| --- | --- | --- | --- |
| 标准完整分类 | 混合一至三级 | 沿用项目默认的细分方式 | 不修改动态子层级 |
| 精简一级分类 | 电影/剧集各七至八类 | 控制目录和媒体库数量 | 不修改动态子层级 |
| 极简三分类 | 每种媒体仅三类 | 只分离动画、纪录或综艺 | 不修改动态子层级 |
| 地区优先分类 | 统一一级 | 按制片国家/地区浏览 | 依赖 TMDB 产地数据 |
| 题材优先分类 | 统一一级 | 按内容题材浏览 | 多题材按规则顺序首次命中 |
| 亲子与分级隔离 | 统一二级 | 先隔离高分级与未知分级内容 | 分级不完整时仍需人工复核 |
| 纪实综艺优先 | 统一二级 | 纪录片、综艺、新闻等收藏较多 | 剧情内容精简兜底 |
| 动漫细分分类 | 统一二级 | 动漫收藏为主、按产地浏览 | 依赖类型和产地数据 |
| 按时长分类 | 统一一级 | 区分短片、常规与超长内容 | 实际时长优先，缺失时用 TMDB |
| 标准分类 + 年代 | 混合静态层级后追加年代 | 需要较细的分类和年代目录 | 覆盖年代子分类开关 |
| 精简分类 + 评分段 | 一级静态分类后追加评分段 | 控制静态目录并按评分浏览 | 覆盖评分子分类开关 |

```yaml
movie:
  动画电影:
    genre_ids: "16"
  其他电影: {}

tv:
  动漫:
    genre_ids: "16"
  其他剧集: {}
```

## 匹配语义

普通条件为 AND；字段名前加 `?` 表示同一 OR 组。一条规则需要所有 AND 条件成立，并且存在 OR 条件时至少命中一项。支持字段包括 `tmdb_id`、`genre_ids`、`original_language`、`origin_country`、`content_rating`、`runtime`、`keywords` 和 `include_keywords` 及界面列出的兼容别名。

包含正向 `tmdb_id` 的固定规则由后端提升到最高优先级，与 YAML 中的位置无关；之后才按书写顺序执行普通规则和兜底规则。同一作品有多个类型或产地时，只进入第一条命中的规则。`classify_by` 已不再支持。

模板只能依据系统支持的 TMDB 元数据分类，不能依据分辨率、编码、HDR、来源站点等文件技术属性分类。TMDB 元数据缺失时，对应条件不会命中并会继续匹配后续规则。

## 提交更新

1. 新增或修改 `online-rules/category/*.yaml`，目录路径保持唯一，兜底 `{}` 放在同一媒体类型最后。
2. 在 `manifest.json` 登记模板，使用不含凭据的完整 HTTPS 地址。
3. 运行项目测试，确认 YAML 语法、字段、目录层级、固定 TMDB ID 和清单均通过校验。
4. 提交 PR，并在说明中写明适用场景、目录层级和是否包含 `sub_classify`。

在线模板只有在用户主动打开弹窗并拉取时访问，不做自动更新检查。应用时只覆盖 YAML 实际包含的媒体类型；其他本地配置保持不变。
