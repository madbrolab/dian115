捐赠、激活与排障

这里合并原 Wiki 中的捐赠与 License Key 说明，以及从容器、路径、账号、网络和任务日志入手的完整排障顺序。

捐赠与激活码

完成捐赠后接收 License Key，并在 DIAN115 首次启动的激活弹窗或激活页中填写。捐赠金额为 199R，备注邮箱是发码和后续核对的依据。

199R 捐赠 · 获取 License Key

  1. 扫码完成捐赠，在付款备注中填写可正常收信的邮箱。
  2. 收到 License Key 后，回到首次启动激活弹窗或激活页填写。
  3. 长时间未收到时联系 @succt，提供捐赠时间、备注邮箱及必要核对信息。

四步排查法

1. 看容器确认状态为 Up，没有反复重启或端口冲突。
2. 看路径确认 /config、/media、/CloudNAS 存在且权限正确。
3. 看账号检查 115、CloudDrive2、PT 或通知凭据是否过期。
4. 看任务展开任务详情和日志，记录失败步骤与原始错误信息。

常见问题

页面打不开

确认访问的是服务器 IP 和正确端口。桥接网络检查端口映射，Host 网络检查宿主机端口是否被占用。

CloudNAS 目录为空

检查 CloudDrive2 是否挂载、共享传播是否开启，以及 DIAN115 是否映射了同一个容器路径。

整理任务失败

查看源路径、目标路径和写入权限。先用单个文件测试规则，再恢复批量任务。

Emby 扫描不到文件

对比 DIAN115 与 Emby 的容器内路径，两边都应使用 /media/...，不要混用宿主机绝对路径。

通知没有发送

重新验证 Bot Token、Chat ID 或 Webhook，确认事件条件满足，并检查网络出口与静默时段。

PT 搜索成功但没有入库

PT 任务完成与 115 秒传、CD2 投递、媒体整理是不同任务。分别查看下载器、后处理和整理日志。

日志与反馈

收集问题时提供版本号、部署方式、复现步骤、预期与实际结果，以及脱敏后的日志片段。不要上传账号 Cookie、Token、二维码或完整配置文件。

可以在 GitHub 仓库提交 Issue，或先阅读 参考手册 和 通知模板 中的字段说明。

维护建议

  • 升级前备份 /config，使用 AI 工具时同时备份 /dian115AI。
  • 定期检查任务队列中长期失败的任务，不要只看容器是否为 Up。
  • 清理缓存前确认没有批量整理正在运行。
  • 每次修改路径后，用小范围任务做回归验证。
  • 对外开放门户或通知时使用 HTTPS、强密码、最小端口和定期备份。
