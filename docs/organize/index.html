使用文档/整理与影库

媒体整理规则

先配置网盘与账号，再做识别测试、共享分类和命名，最后创建规则。实体视频规则固定排除 .strm。

开始前先阅读主账号与扩展目录

1. 准备网盘和账号

确认容器本地可访问挂载、网盘服务生效，主账号与云盘映射可用。

2. 先验证识别

到“整理工作区 → 识别测试”输入一个实际文件名，按需求选常规识别或 AI 兜底，再看结果。不要一开始就在全部真实文件上执行整理。

3. 先配共享规则

分类配置维护电影/电视剧分类；全局设置维护命名、并发、版本优选、输出字段。源/目标和移动方式由单条整理规则决定。

4. 填写规则基础与路径

“整理规则 → + 添加规则”填写规则名称、启用状态、输入类型。默认视频文件规则只处理实体视频并固定排除 .strm；虚拟文件要单独选“虚拟影库 STRM”。选择源路径、其下排除目录、目标路径及一级类型目录/二级分类目录开关。

5. 选择处理和清理策略

配置失败处理、整理方式、智能清理、同步字幕、TMDB 元数据刮削和自动监控。智能清理会在主文件/字幕处理后删除不再含视频（虚拟影库为不再含 STRM）的目录及残留文件，可向上清理空父目录，源目录本身保留。

6. 明确版本和过滤后保存

设置整理策略、重复文件策略、前置过滤、被排除时删源、AI 增强、FFprobe、小文件阈值、包含/排除格式。AI 总开关关闭后细分开关均失效；大小为 0 不限制；视频规则不处理 m2ts/BDMV 原盘。核对后点弹窗“保存”。

7. 从历史验证结果

“处理记录”按标题/路径、状态、模式筛选，查看成功、失败、跳过和事由，再针对具体记录处理。任务执行进度到统一任务队列核对。
