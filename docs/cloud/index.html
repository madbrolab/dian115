使用文档/设置与维护

基础设置与网盘文件服务

按本页独立保存按钮配置；网盘服务保存后需要重启。CD2 填实际最终挂载点，例如 /CloudNAS/CloudDrive；挂载源目录和 API Token 根目录都必须选 /。界面主题和动效是浏览器即时设置。

1. 先确认 CD2 实际最终挂载点

CD2 挂载根目录填写 CD2 配置的实际最终挂载点。例如挂载名称为 CloudDrive、挂载父目录为 /CloudNAS 时，填写 /CloudNAS/CloudDrive，其中 CloudDrive 是 CD2 的实际挂载名称。优先用“自动读取”核对 CD2 API 返回的挂载点；不要仅根据宿主机与容器的卷映射推导或改写这个字段。该实际挂载点同时需要在 DIAN115 中可访问，挂载传播或可见性问题应单独检查部署映射。未知 CD2 实际挂载点时先询问用户。

2. 配置网盘文件服务

在“基础设置 → 网盘文件服务”选择实际使用的 CD2/AURA。CD2 表单有 CD2 地址、API Token、CD2 挂载根目录。CD2 的挂载源目录必须选择根目录 /；供 DIAN115 使用的 API Token 根目录也必须选择 /，不能只授权某个云盘或其子目录。Token 还需具备所需的文件读取、创建、修改与删除权限。挂载设置和 Token 授权可对照首次配置引导中的两张参考图。填写地址与 Token 后保存，点击“自动读取”核对实际最终挂载点；手动选择时也必须选择该挂载点。

3. 选择AURA时核对独立配置

AURA分支填写AURA地址、API Token、AURA挂载根目录；已保存令牌时留空保留原令牌。自动识别读取AURA挂载列表并检查目录在DIAN115内可读，路径映射不同时手动选择；多候选时选择实际使用目录。先测试连接，再点保存文件服务，重启后生效。CD2和AURA配置分别保留。

4. 测试、单独保存、再重启

先点网盘服务区的“测试连接”，确认结果后点“保存 CD2 设置”。页面明确提示保存后重启才生效，切换服务会保留两套已保存设置。不要把测试成功当成已经保存。

5. 按需配置语言和 TMDB 地址

界面语言即时生效；TMDB 语言要点“保存 TMDB 语言”。API 地址与图片地址在“TMDB 服务地址”单独选择，并点“保存 TMDB 地址”。

6. 配置系统参数

前端日志保留只影响内存日志且重启清空；单个日志文件大小、滚动文件数量、文件写入队列控制落盘。队列满时丢弃文件日志而不阻塞 STRM。Worker 并发数与哈希计算线程分别控制任务并发和 CPU 槽位，最后点“保存系统参数”。

7. 有需要才配置代理与过盾

HTTP 代理地址及自定义代理域名一行一个，匹配子域名；先测试再“保存代理设置”。FlareSolverr 按官网部署：推荐 DIAN115 Host + 同机 FlareSolverr，将 127.0.0.1:8191:8191 映射到宿主机，服务地址填 http://127.0.0.1:8191；只有两个服务都在同一桥接网络时才填 http://flaresolverr:8191。保存 FlareSolverr 设置后测试连接；留空表示未配置，不回退环境变量。完整部署查询 部署 DIAN115-flaresolverr。

8. 检查数据库维护状态

数据库维护显示最近成功/尝试时间及摘要。“刷新状态”仅查询，“立即维护”会执行维护。遇到部分完成先看具体摘要，不凭状态推断损坏，也不要直接要求在线强制缩库。

9. 查看和维护当前数据库

基础设置下方“数据库维护”显示当前实际数据库。PostgreSQL 展示库名、版本、占用、业务表和连接统计；“立即维护”执行过期记录清理、普通空间整理与统计更新，并返回进度和结果。新装和迁移分别查询 使用 PostgreSQL 新装 DIAN115、把旧 SQLite 数据迁移到 PostgreSQL，完整维护说明查询 查看和维护当前数据库。

字段说明

字段填写方法
CD2 挂载根目录填写 CD2 的实际最终挂载点，例如 /CloudNAS/CloudDrive，CloudDrive 为实际挂载名称；按 CD2 配置或自动读取结果核对，不要仅按 Docker 卷映射改写。该目录须在 DIAN115 中可访问，保存后重启。
CD2 挂载源目录在 CD2 挂载设置中选择根目录 /。示例挂载名称 CloudDrive、挂载父目录 /CloudNAS，最终挂载点为 /CloudNAS/CloudDrive。
CD2 API Token在 CD2 编辑令牌时，根目录必须选择 /，并授予所需文件读取、创建、修改与删除权限。根目录 / 是授权范围，与 API 服务地址不同。
自动更新页面说明需要具备 Docker socket 访问能力；仅部署主程序并不自动具备。
动效强度完整、轻柔、关闭，浏览器本地即时生效。
AURA 地址填写DIAN115容器可访问的AURA服务地址，示例不是实际部署地址。
AURA 挂载根目录DIAN115容器内可读目录；自动识别后核对映射并保存，重启生效。

常见问题

CD2 连接测试通过，但目录为空或自动读取失败

不能只凭连接测试通过就认定路径填错。依次核对 CD2 挂载源目录是否为 /、API Token 根目录是否为 / 且权限足够、实际最终挂载点是否与配置一致、所选云盘是否对应正确的 115 账号，再检查挂载传播和 DIAN115 中的目录可见性；结合实际报错定位。
