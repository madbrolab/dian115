CD2、DIAN115 与 Emby 路径搭配

同一份文件，在宿主机和各容器里分别叫什么，一次说清。

1. 1. 两个共享目录，三套容器

云盘挂载目录用来接收 CD2 的 FUSE 子挂载；媒体目录用来保存整理输出或本地 STRM。CD2 发布挂载，DIAN115 与 Emby 接收挂载。DIAN115 和 Emby 的宿主机来源、容器目标路径保持一致。

配置 / 命令
# CloudDrive2
volumes:
  - /mnt/cache/CloudNAS:/CloudNAS:shared

# DIAN115
volumes:
  - /mnt/cache/CloudNAS:/CloudNAS:rslave
  - /mnt/user/media:/媒体库

# Emby：与 DIAN115 的宿主机目录、容器目标路径一致
volumes:
  - /mnt/cache/CloudNAS:/CloudNAS:rslave
  - /mnt/user/media:/媒体库

2. 2. 路径对照表

左侧是宿主机目录，右侧才是程序配置要填写的容器路径。:shared 与 :rslave 是卷挂载选项，不是路径名称的一部分。
位置 / 用途：宿主机云盘目录；示例路径或配置：/mnt/cache/CloudNAS；在哪里使用：CD2、DIAN115、Emby 的 volumes 左侧
位置 / 用途：CD2 发布挂载；示例路径或配置：/CloudNAS:shared；在哪里使用：CD2 的 volumes 右侧
位置 / 用途：DIAN115 / Emby 接收；示例路径或配置：/CloudNAS:rslave；在哪里使用：两个容器的 volumes 右侧
位置 / 用途：CD2 自动读取挂载点；示例路径或配置：/CloudNAS/CloudDrive；在哪里使用：DIAN115 → 系统设置 → 网盘文件服务
位置 / 用途：主账号云盘名称；示例路径或配置：115open（示例）；在哪里使用：账号配置中选择真实 CD2 云盘
位置 / 用途：云盘中的电影目录；示例路径或配置：/CloudNAS/CloudDrive/115open/电影；在哪里使用：文件管理 / 规则的本地挂载路径示例
位置 / 用途：宿主机媒体输出；示例路径或配置：/mnt/user/media；在哪里使用：DIAN115 与 Emby 的 volumes 左侧
位置 / 用途：容器媒体输出；示例路径或配置：/媒体库/strm；在哪里使用：DIAN115 的 STRM 输出与 Emby 扫描目录

3. 3. shared 与 rslave 为什么不同

CD2 使用 shared 将云盘子挂载传播到宿主机。DIAN115 与 Emby 使用 rslave 接收宿主机的挂载变化，CD2 重启后重建的子挂载也能继续看见。宿主机传播未配置时，单独写 :rslave 无法解决问题。修改 volumes 后需要重新创建容器。

4. 4. 挂载点、云盘名与目录不要混用

/CloudNAS 是容器卷根；/CloudNAS/CloudDrive 是自动读取的挂载点；115open 是 CD2 的云盘名称。真实云盘名以自己的 CD2 为准。CD2 API 的目录选择器和本地文件选择器可能显示不同前缀，应使用对应入口选择目录。

5. 5. 从 STRM 输出到 Emby 扫描

例如 DIAN115 把 STRM 输出到 /媒体库/strm，Emby 也将这个目录作为媒体库目录。容器中的 /媒体库/strm 实际对应宿主机 /mnt/user/media/strm。若已有 Emby 路径不同，先配置路径转换并检查匹配，再扫描，避免重复条目。

6. 6. 按配置引导逐步验收

先对齐三套 Compose → 在 CD2 挂载根目录并生成 Token → DIAN115 保存 CD2 地址并自动读取 → 添加 115 主账号并选云盘 → 配置整理与 STRM → 首次全量同步 → 在我的媒体控制中心接入 Emby。先用一部作品确认读取、输出和播放，再扩大范围。
