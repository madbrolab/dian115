STRM 规则

从 115 源目录生成本地 STRM；与虚拟影库的分享解析生成分开。

开始前先阅读主账号与扩展目录

1. 配置账号与云盘

先完成主账号的云盘名称和目录配置。CD2 路径模式还需确认网盘服务和本地挂载。链接模式无需 CD2。

2. 填写来源和输出

媒体整理切到“STRM规则 → 新增规则”，可选已有规则作模板；填写规则名称、确认云盘名称，选择 115 网盘源路径与容器本地输出路径。

3. 选择生成模式

CD2 路径模式按挂载生成；选择“链接模式（无需CD2）”后新增“服务地址”，填写实际 DIAN115 内网地址并确认播放器能访问。不能照抄审阅实例地址。

4. 设置生成和同步

“启用”与“生成 STRM”是独立开关；定时同步、实时监控都不勾选时为手动模式。全量同步频率单独配置，文件后缀可用视频/音乐快捷选择。

5. 展开高级选项

排除目录只能在源目录内选择且排除整棵子树；配置元数据后缀、元数据同步、智能清理。智能清理未开启时，清理孤立文件仅删除 STRM 文件本身。

6. 迁移先备份再创建

从其他工具迁移时，页面要求先配置 115 账号、癫影 OpenAPI、emby-ffp-seed、Madby 并完整备份 Emby 数据，再开启生成 STRM。核对无误点“创建”，随后看目录树、最后同步和任务进度。
