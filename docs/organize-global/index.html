全局命名、并发与版本优选

四个分区的改动通过“保存全部设置”一起保存。

1. 编辑基础命名

全局设置包含命名与版本、并发处理、版本优选、输出字段四个分区。电影和剧集模板可切换可视化/源码，拖动片段、插入变量和固定文字；路径 / 创建下一级目录，实时预览包含最终扩展名。

2. 按需启用多版命名

多版命名是独立模板，启用后多版共存/多版本洗版可使用版本标识的专用目录。未启用时不要指导用户填写不可见的多版字段。

3. 设置并发与质量顺序

并发整理数页面明确默认 1、最高 3。洗版评分可启停并拖动各维度，包含分辨率、片源、编码、格式、音频、HDR、色深、帧率、字幕、文件大小。它控制评分洗版/多版本洗版的优选。

4. 映射显示值并统一保存

字段别名把已识别值映射为自定义输出，例如 2160P→4K，不是修改远端原始文件名的通用规则。核对实时预览后点底部“保存全部设置”。
