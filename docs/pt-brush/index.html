PT 刷流任务配置

每任务独立绑定站点与下载器，同站点可建多个策略；先准备连接再建立规则。

开始前先阅读PT 站点与 RSS下载器配置

1. 先准备站点和下载器

先配置可用站点与下载器，再返回刷流新增任务。下载器本地目录需按实际容器映射配置。

2. 设置站点与调度

新增任务填名称、站点、下载器、保存目录（留空跟随下载器）、刷新和检查间隔。定时表达式填写后替代刷新间隔；活动时间可多段。任务启用、通知、启动刷一次分别选。

3. 设置候选筛选

选种规则包括促销、H&R、体积、人数、发布时间、时间偏移、包含/排除正则。正则匹配标题和副标题，同类任一匹配；RSS信息不足不能通过免费/H&R筛选，两项均不限可加入但按H&R保护。无发布时间不能通过时间限制。

4. 设置任务限额

容量、下载数只计算本任务托管种子，带宽阈值检查整个下载器。各限额0关闭；最小剩余空间不足或预计新增超容量会暂停新增。

5. 明确删种会删除数据

自动删种同时删除下载器任务与对应数据。保留标签优先；H&R只按专用时长或目标分享率判断，不能被普通条件绕过；普通种子任一条件达标可删。核对后保存任务。

6. 再配置全局调度

全局设置独立启用自动调度、总容量/下载数/带宽与动态删种；保存全局设置后重新调度。全局限额不取代各任务限额。

字段说明

字段填写方法
动态阈值50-100达到100GB清到50GB；单值上限和目标相同。启用全局动态删种优先全局阈值。
下载器标签每个任务可自定义一个标签，默认刷流，留空不添加；修改仅应用于新种子，任务归属不依赖标签。
保留标签逗号或换行，精确匹配下载器标签。
免费到期删除未完成下载依赖站点明确返回截止时间，仅用于免费促销筛选任务。
停止单种托管在种子记录中点击停止托管，保留下载器种子、文件及历史统计；修改或移除标签不会退出托管。
