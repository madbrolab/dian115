# DIAN115 推送助手（Chrome / Edge 浏览器扩展）

一个插件两条推送链路：视频页面（含节目单）推给 DIAN115 **视频下载器**；
115 分享、磁力、ED2K 链接推给 DIAN115 **外部推送**插件完成转存或离线。
扩展只调用主程序已有的 OpenAPI，不依赖网页账号登录。默认不读取或上传 Cookie；手动开启站点 CK 同步后，只同步当前站点。

> 「站点 CK」相关说明见下文：只有在设置里**手动开启**「推送时同时更新站点 CK」
> 后，扩展才会读取并上传当前站点的 Cookie；默认关闭，关闭时不会读取任何 Cookie。

## 目录

```
browser-extension/video-downloader/
  manifest.json      MV3 清单
  icons/             图标
  src/common.js      设置、请求、格式化工具
  src/links.js       115 分享、磁力、电驴识别与同页去重
  src/content.js     链接旁推送图标、页面叠加层和批量列表
  src/background.js  右键菜单、预检、批量确认、进度轮询
  src/popup.html     弹窗界面
  src/options.html   设置界面
  src/style.css      与推送助手一致的卡片式外观
```

## 安装（开发者模式）

下载地址（打包好的 zip，`manifest.json` 就在压缩包根目录）：

```
https://raw.githubusercontent.com/madbrolab/dian115/main/browser-extension/video-downloader-extension.zip
```

1. 下载上面的 zip。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开右上角“开发者模式”。
3. 先将 zip 完整解压，再点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。
4. 记下扩展卡片上显示的 ID。

更新到 **1.2.5** 后请重新加载扩展，并刷新已打开的网页，让新增的页面链接图标生效。

## 在 DIAN115 一侧准备

1. 打开“插件 → 视频下载器 → 外部 API”，启用外部 API。
2. 确认“外部 API”已启用即可。外部接口现在**只校验 OpenAPI Key**，不再需要填写允许来源。
3. 复制系统设置里的 OpenAPI Key。
4. 打开扩展的“设置”，填入服务器地址与 OpenAPI Key，点“测试连接”。
   返回“连接成功”即代表鉴权与来源校验都已通过。

## 用法

- 页面空白处右键 → **推送到 DIAN115 下载**：推送当前页面。
- 115 分享页、资源链接或选中资源文字上右键 → **推送到 115（转存 / 离线）**：识别页面/链接/选中文字里的
  115 分享链接、磁力链接、ED2K 链接，交给 DIAN115 的「外部推送」插件处理。
- 页面空白处右键 → **推送当前页面节目单（列表探测）**：先展开节目单，
  弹窗里会显示条目数、预计体积和队列剩余，再决定是否加入。
- 链接上右键 → **推送此链接到 DIAN115**。
- 框选多个链接后右键 → **推送选中的链接到 DIAN115**（一次最多 100 条）。
- 弹窗里点「节目单」，或右键做一次列表探测后，预览卡片会列出服务端解析到的
  全部格式：推荐项带 `★`，并标注分辨率、编码、容器、体积和是否需要合并音轨；
  选好格式再点「加入下载队列」，该格式只对这一次推送生效。
- 点击工具栏图标可以查看预检结果、最近推送的进度和批次汇总。
- 页面内检测到 115 分享、磁力、ED2K 后，在链接旁显示可点击的 `↥` 图标。
  同一个页面里同一资源只显示一个图标，重复分享链接中的提取码会保留。
- 本页有多个不同资源时，弹窗的「格式」区域和页面叠加层显示「批量推送」入口。
  打开列表后可单选、多选、全选、逐项删除、删除选中、推送选中或一键推送全部。
  删除只移除本次列表项，原网页链接保留。关闭弹窗后已接受的批量任务继续处理。
- 扩展设置里的「页面叠加层」可以关闭网页图标和浮动批量入口，弹窗列表仍可使用。
- 普通视频页面只有检测到实际的 115／磁力／ED2K 资源后才显示 115 卡片；
  视频和节目单由服务端站点提取器识别，自动节目单探测可在设置里关闭。

## 115 转存 / 离线（用 DIAN115 已保存的账号）

115 的账号与目录**不需要在扩展里登录**：扩展通过 OpenAPI 读取 DIAN115 里已经
保存好的 115 账号，并用该账号列目录拿 CID。

1. 打开扩展弹窗 → 「115 转存 / 离线」卡片 → 选择账号 → 点「转存目录」或
   「离线目录」逐级浏览，选好后点「选当前目录」。
2. 点「保存为默认」，下次推送就沿用这套账号和目录。
3. 在 115 分享页/磁力链接页右键 → **推送到 115（转存 / 离线）**，
   或直接在弹窗里点「推送到 115」。

这两份配置分开保存：

| 存储键 | 内容 | 影响范围 |
| --- | --- | --- |
| `settings` | 视频页面推送：模式、画质、目标目录、站点 CK、确认阈值、通知 | 只影响「推送到 DIAN115 下载」 |
| `push115` | 115 账号 + 转存目录 CID + 离线目录 CID | 只影响 115 转存/离线 |

也就是说：**改 115 的账号/目录不会动到页面推送的下载配置**，反之亦然。

## 大量文件的确认规则

推送前扩展会先向服务器做一次预检。命中下面任意一条时，不会立刻建任务，
而是先弹出确认（右键流程用系统通知的“确认加入 / 取消”按钮）：

- 服务器认为这批任务需要确认（条数、体积或队列余量任一超限）；
- 条目数超过设置里的“多少条以上先让我确认”；
- 预计体积超过设置里的 GB 阈值；
- 条目数超过当前队列剩余名额。

确认时会带上服务器签发的确认令牌，令牌只对这一次的页面地址和条目数有效，
避免“预览 1 条、实际提交 500 条”。

## 去重

页面去重指的是：**同一页面多个相同的 115 分享／ED2K／磁力链接只保留一个资源项**。
115 按分享码合并并保留提取码；磁力按内容哈希合并，不受名称和追踪器参数影响；
ED2K 按文件哈希合并，不受文件名变化影响。批量提交同一资源一次。

扩展不会用历史推送记录阻止主动再次推送。服务器原有的任务去重规则仍然生效，
若服务器返回重复任务，界面显示“已存在，未重复创建”。

## 站点 CK（推送时同步登录态，默认关闭）

DIAN115 的「视频下载器 → 站点 CK」用于需要登录的站点。除了在网页端手动粘贴
或从 CookieCloud 导入之外，扩展还可以在推送的同时把当前站点的 Cookie 一并同步：

1. 打开扩展设置 → 「站点 CK」→ 勾选 **推送时同时更新站点 CK**（默认不勾选）。
2. 之后每次预览或推送当前页面时，扩展会读取该站点的 Cookie 并发给 DIAN115；
   服务器会把它们合并进绑定同一域名的 CK 配置（同名站点重复推送只更新，不新建）。
3. 同步失败不会影响下载任务的推送，通知里会单独说明。

关闭该选项时，扩展不会调用 `chrome.cookies`，也不会发送任何 Cookie。
该选项只建议对自己搭建的服务器开启。

## 权限说明

- `contextMenus` / `tabs`：获取右键目标与当前页面地址。
- `storage`：保存服务器地址、OpenAPI Key 和最近推送记录。
- `notifications` / `alarms`：批量确认与下载完成提醒。
- `cookies`：仅在「推送时同时更新站点 CK」开启后用于读取当前站点 Cookie；
  关闭时扩展不会读取任何 Cookie。
- 扩展**不读取、也不保存 115 登录态**：115 目录浏览由 DIAN115 服务端用它自己
  保存的账号完成，扩展只拿到目录名与 CID。
- `http://*/*`、`https://*/*`：DIAN115 是自托管服务，地址由使用者填写，
  因此无法在清单里写死域名；页面脚本也在这些页面中检测资源链接。
  页面检测在本地进行，点击推送后才把所选链接提交给 DIAN115，网页拿不到 OpenAPI Key。

## 自检清单（首次安装后建议走一遍）

1. 扩展设置里填服务器地址与 OpenAPI Key，点“测试连接”应显示连接成功
   （只校验 OpenAPI Key，不再需要放行来源）。
2. 打开一个普通视频页，右键“推送到 DIAN115 下载”，应弹出“已加入 1 个任务”。
3. 打开一个节目单页，右键“推送当前页面节目单（列表探测）”，确认卡片应显示
   条目数、预计体积、队列剩余；取消后不应产生任务。
4. 打开包含重复资源链接的页面，批量列表应只保留不同资源；再次主动点击图标仍可提交。
5. 打开「推送时同时更新站点 CK」后再推一次，通知应出现“已同步站点 CK N 条”；
   到网页端「视频下载器 → 站点 CK」能看到该域名的配置被更新。
6. 在 115 分享页右键「推送到 115（转存 / 离线）」，按提示先选一次账号与目录并
   「保存为默认」，再推送应提示“已完成”，且网页端「外部推送」里能看到记录。


## 1.2.5 站点识别与页面资源推送

预览和推送同步使用用户开启的站点 CK；自动列表探测交给提取器识别节目单。
已识别但暂时没有可下载格式的页面显示登录态或访问限制提示。能识别页面不代表站点
已经允许下载，实际任务仍需站点返回媒体格式；遇到访问限制时可更新站点 CK 或稍后重试。

新增资源图标、叠加层开关、格式区批量列表和同页资源去重。批量提交保存在扩展后台，
工作线程中断后从已保存位置继续，恢复同一项时沿用同一请求标识。

无需浏览器的回归检查：

```sh
node --experimental-vm-modules --test browser-extension/video-downloader/tests/logic.test.mjs browser-extension/video-downloader/tests/links.test.mjs
```

浏览器交互检查使用可选的 Playwright：设置 `DIAN115_PLAYWRIGHT_MODULE` 为已安装的
Playwright `index.mjs` 绝对路径，必要时用 `DIAN115_CHROMIUM_PATH` 指定 Chromium，
再运行 `node --test browser-extension/video-downloader/tests/browser.test.mjs`。
测试使用模拟网页和接口，覆盖链接去重、动态扫描、文字保留、叠加层开关、批量删除和弹窗入口。
